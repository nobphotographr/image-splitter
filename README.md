# Image Slicer

1枚の画像を、XなどのSNSへ投稿しやすい2〜4枚の連続画像に分割するWebアプリです。

## 特徴

- 縦方向または横方向へ2分割・3分割・4分割
- 縦画像を左または右へ90度回転してからカルーセル分割
- 右回転時も元画像の上から順にファイル番号を自動調整
- 1枚あたり3:4または4:5へトリミング可能
- ドラッグ&ドロップ対応
- 日本語／英語／韓国語／簡体字中国語／繁体字中国語の表示切り替え（ブラウザ言語による初期選択、端末内に設定保存）
- ブラウザ上で完結（データ保存なし）
- レスポンシブデザイン
- ダークモード対応

## 使い方

1. 画像をドラッグ&ドロップするか、ファイルを選択
2. 分割方向、枚数、回転方向を選択
3. 自動的に分割されます
4. 個別に保存するか、まとめて保存・共有
5. ファイル番号の順にSNSへ追加

## 開発

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いて確認できます。
